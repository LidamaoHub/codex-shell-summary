---
name: shell-summary-isolation
description: 使用 Shell摘要隔离本地插件执行 Shell、继续等待或按执行编号查询。适用于已安装且执行权限配置已确认的插件；不自动安装或修改全局配置。
---

执行 Shell 时，将原生 `exec_command` 的参数原样传给本插件同名工具，只更换工具入口。不要新增 question/model、改写命令或强制补充 workdir。插件内部使用独立原生 Codex 请求分析输出，不继承本会话历史。

- `execution_status=running` 时，用本插件 `write_stdin` 等待，沿用原生参数。会话编号属于本插件，不能传给原生 Shell。
- 仅在 `command_executed=false` 且 `fallback_required=true` 时回退原生 Shell；交互、TTY、已知常驻命令和需原生审批的命令由原生处理。
- 命令已执行后，即使摘要失败、取消或超时，也不能通过回退或解释重试再次执行。
- 普通输出按 execution_id 保存为本地编号日志；`reinterpret` 读取文件进行独立解析，服务重启后仍可用。不要求主模型直接读取整份日志。
- 敏感输出直接返回原文，不保存文件或内存副本；重新解释中新检测到敏感信息时删除对应日志。再次查询原文不可用，只报告需要重新调用，不自动重跑。
- 解析失败时，向用户明确说明解析出了问题，并使用工具交回的原始输出；原文和编号日志已清除，不能再按编号解释。命令已执行，不能因此自动再次执行。

- cat、ls/tree、搜索、JSON、diff 等结果需要精确内容。使用 analysis.body 中的精确内容、analysis.attention 中的注意事项和覆盖标记，不把读取成功解释成代码运行验证成功。
- 不读取解析器临时目录或尝试恢复完整日志。主会话接收到的正文与注意事项仍可能被 Codex 记录。

工具未发现时说明情况。用户只授权暂不支持的执行场景回退，不应把插件缺失静默当成正常支持。
