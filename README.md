# codex-shell-summary

Shell摘要隔离：本地执行 Shell，将输出交给全新的原生 Codex 会话解析，主会话接收有用正文与注意事项，减少重复进度进入上下文。实验版 0.3.0；目前支持 macOS，本机验证使用 Codex CLI 0.147.0，其他版本和另一台实体电脑尚待验收。

无需额外模型 API key，不部署远程执行服务。解析使用本机已登录的 Codex，默认 `gpt-5.6-luna` / `low`；模型调用仍需要联网，并消耗当前账号额度。它不是离线模型，也不是 Shell 沙盒替代品。

## 安装到另一台 Mac

先安装并登录 Codex CLI，准备 Python 3.9+、Git。使用该电脑自身的登录，不复制其他电脑的登录文件。

```bash
git clone https://github.com/LidamaoHub/codex-shell-summary.git
cd codex-shell-summary
python3 scripts/install_local.py --workspace "$HOME/你的项目目录"
```

最后一条只预览，不修改全局配置。将路径替换为真实存在的项目目录，审阅输出后执行：

```bash
python3 scripts/install_local.py --workspace "$HOME/你的项目目录" --apply
```

`--apply` 明确启用该目录及子目录的本机 Shell 执行，并调用 Codex CLI 注册本地插件源、安装插件；会影响目标电脑的插件缓存、来源登记和用户插件配置。不写全局 AGENTS。插件的执行是 `unrestricted-local`，不继承主会话的原生沙盒或审批；工作区检查只是 cwd 限制，不能阻止命令访问目录外的文件。需原生审批、TTY、交互等场景会在执行前明确回退。

安装脚本检测该电脑的 Python/Codex 路径，生成到 `$CODEX_HOME/plugin-sources/codex-shell-summary`（默认 `~/.codex`），不会携带作者电脑路径。重启 Codex、开新会话后，Codex 自动启动 stdio 插件服务，无需手动运行服务或保持 Terminal 开启。

目前采用“下载源码→本机生成插件源”的安装方式。直接把这个 GitHub 仓库作为可运行插件源尚未验证，不能替代上述步骤。代码更新后 `git pull`，重新预览并应用安装，再重启 Codex；普通编号日志保存在插件缓存之外。

## 新会话使用

安装成功不代表每条 Shell 会自动被强制拦截。可以在独立会话中输入：

> 本会话执行 Shell 优先使用 Shell摘要隔离插件的 exec_command，只更换工具入口，沿用原生参数。运行中用插件 write_stdin。需要进一步解释时，用 execution_id 调用 reinterpret。仅在明确未执行且要求回退时用原生 Shell；命令已执行后，不因解析失败重新执行。解析失败时提醒我，并使用插件交回的原文。

需要“全部必须插件”的测试可另行禁止回退；未支持场景会停止，不应算插件验收通过。

## 输出与日志

- 安装、构建等输出：过滤无用重复进度，保留完成结论、错误和警告。
- ls、grep、cat、JSON、diff 等查询：预算内保留完整有用内容，不用数量、范围或示例代替完整结果。
- 普通输出：整次判断完成后写入 `~/Library/Logs/CodexShell/<execution_id>.log`；文件包含命令、状态及两路原文，完成后释放插件原文缓冲。
- 按编号再解释：读取编号文件，发起全新的独立解析，不重新执行命令，重启后仍可查询。
- 检测到敏感内容：本次直接向主会话返回原文，不保留编号文件或插件原文内存；后续要求重新调用。重新解释时新检测到敏感信息，会删除旧文件。
- 解析错误、超时、返回预算失败：交回原文、提示解析问题，不留编号文件或插件原文内存，不自动重跑命令。

敏感原文进入主会话是此项目的设计选择；插件清除不删除主对话记录，也不承诺服务端、系统交换文件或物理内存安全擦除。AI 敏感检测存在漏检可能，普通日志本身可能需要用户自行清理。

## 边界与验证

默认最多并发 2 条命令，单条采集 8 MiB、执行 120 秒，单次解析 90 秒。超限会明确报告；失败原文回传仍受返回预算约束，不能保证任意大输出全部进入主会话。`SHELL_SUMMARY_MODEL`、`SHELL_SUMMARY_LOG_DIR`、`SHELL_SUMMARY_SEGMENT_BYTES` 等环境变量可配置，具体见 `server.py`。

```bash
python3 -m unittest discover -s tests -v
```

测试使用临时目录与模拟解析器，不需要模型登录，也不代表另一台实体电脑已验收。原生模型/MCP 历史验收未公开原始会话记录或用户日志。解析较长精确内容会增加输出 token 和延迟，不能用省掉有用内容计算节约；解析自身和重解释的用量需要计入净成本。API 价格不能直接换算 Codex 五小时额度。
